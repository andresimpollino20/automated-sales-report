# Dashboard Access

Interactive version: [Automated Sales Report 2025](https://docs.google.com/spreadsheets/d/1THt9u8sw1mRxW28qljmpSoeEN-kNSqSmX-nY9JkyBPI/edit)

Before adding this project to a public portfolio:

- provide view-only access or publish a sanitized copy;
- confirm that hidden and technical tabs do not expose private configuration;
- keep source data anonymized;
- test the Month, Channel, and Province filters in an incognito browser.

An exported spreadsheet can be added here for reference, but the native Google Sheets version is the recommended interactive deliverable because Google-specific formulas and controls may not behave identically in Excel.

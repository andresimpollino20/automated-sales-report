# Project Images

The final dashboard screenshot is available as:

`dashboard.png`

Capture guidelines used for the portfolio version:

- use the live Google Sheets dashboard;
- hide the formula bar, sheet tabs, gridlines, and unnecessary browser chrome when possible;
- keep the full dashboard visible in one frame;
- use the default `All` filter state;
- export at a width of at least 1600 px;
- verify that no private account or customer information is visible.
